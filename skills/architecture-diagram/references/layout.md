# 版面与走线

`examples/zstack_overview.py` 是全部原语的完整可运行实例，坐标和网格可直接参照修改。

## 尺寸

- viewBox 宽 1360（全景）；页面里 `.figscroll svg` 设 `min-width: 1240px`，手机上在图框内横向滑动看图，页面本身不出现横向滚动条。
- 字号：方框标题 12.5、正文 11、线标签 10、区块备注 10.5。字放不下就改短措辞或加宽方框，字号不往下压。
- 方框：标题基线 `y+18`，正文行 `y+34, +48, +62`，所以三行正文的框高至少 68；四行用行距 13、框高 76。
- 区块（zone）：浅色底、无描边，左上是层号小胶囊＋区块名，右上是一句备注；内容从区块顶部 +28 开始。

## 走线

- 先留**通道**：相邻两行区块之间留 14–18px 空带，水平走线走在通道里；两列区块之间留 40–60px，竖向拐线和线标签放在这里。
- 折线（dogleg）的竖段错开 x，横段错开 y，保证互不相交。同一个方框侧边进两条线时，入口 y 至少差 16。
- 躲不开的交叉画**跳线**：竖线在交叉处用 `A5,5 0 0,1` 画半圆，图注里说明"跳线不相连"。
- 汇流线（多个来源汇到一个平台，如所有模型调用）沿外侧走一条总线，支路接入处画小圆点。
- 线标签放在线的上方或右侧、避开区块头文字；穿过区块头的竖线要避开头部文字的 x 范围。
- 顺序流程用箭头形方框（`chevron`），相邻即表示"然后"，不再重复画箭头。

## 打码条

`box(..., chip='私有仓库')` 把黑条右对齐画在标题行，`chip_on_line=i` 画在第 i 行正文末尾。黑条只放行尾：它的位置不依赖前面文字的估算宽度，不会和字重叠。

## 主题

颜色全部走 CSS 变量（`svgkit.CSS` 的 `:root` 与暗色块）；SVG 元素只挂 class，不写硬编码色值。改配色只改变量。
