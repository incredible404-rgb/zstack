---

本人看不懂一条消息，要你把它**重讲**成一读就懂的话。重讲只换说法，不加事实：原文没说的写"原文没说"，不替它补推测。

## 步骤

0. **认对象。** 本人指的是 agent 写的一段话（回复、推送、报告、审查记录）才往下走。指的是题目、文档、论文或某个技术概念，就直接讲那个内容，本技能到此为止。两种都说得通时问一句："你是指我刚才那段话，还是问题本身？"
   完成：确定要重讲的是 agent 写的话。

1. **找到那条消息。** 本人贴了原文就用原文；说"上一条""刚才那条"就是本会话里 agent 的上一条回复；说"那条推送"就按项目文档指明的通知日志路径读取最近一条（日志被截断时，缺的部分照实说没看到）。找不到就问本人要原文，别猜是哪条。
   完成：手里有一段确定的原文。

2. **查词。** 项目里有术语表就读它（如 `GLOSSARY.md`、`docs/glossary.md` 或 `术语表.md`），只看原文里出现的词；其余的内部词（编号、字段名、脚本名、内部简称）去它指向的权威入口查一眼。
   完成：原文里每个外人看不懂的词，都知道它指什么，或确认查不到。

3. **重讲。** 按下面三段写，总长不超过原文：
   - **一句话**：发生了什么、对本人有什么影响，用日常大白话讲。
   - **要你做的**：要本人动手或回复的事，一行一件，带"不回复就会怎样"；没有就写"不用做什么"。
   - **词**：原文里的生词一行一个，`原词：大白话`，叫法照术语表；原词保留，下次本人能认出来。

   本人在手机上（经移动端聊天桥问的）就写纯文本，不用 Markdown 粗体、表格和反引号。

4. **补术语表。** 有词术语表里没收、又是这个项目反复会说的，在末尾加一行"术语表待补：词1、词2；回「补」就写进去，不回复就不补"。本人回"补"，按术语表开头写的格式补条目。
